## Описание проекта

Программный комплекс **«Сервис поиска попутчиков»** разработан в среде **Microsoft Visual Studio 2022** на языке **C# (.NET 9.0, Windows Forms)** с использованием встраиваемой реляционной СУБД **SQLite** (`Microsoft.Data.Sqlite`).

---

## Версии программного комплекса

### Версия 1.0 (Тег `v1.0` — Базовая версия)
- Базовая экранная форма `MainForm` со списком доступных поездок (`DataGridView`), фильтром маршрутов и формой добавления нового рейса.
- Локальная БД SQLite (`carpooling_v1.db`): таблицы `Trips` и `CostExperiments`.
- Математический модуль `ExperimentCalculator`: расчет топливных затрат $C_{fuel}$, амортизации $C_{deprec}$, доли затрат на одного участника поездки и экономии водителя.

### Версия 2.0 (Тег `v2.0` — Окончательная версия)
- **Форма авторизации и регистрации (`LoginForm`):** разделение ролей «Водитель» и «Пассажир», хеширование паролей алгоритмом SHA-256, быстрый вход тестовыми аккаунтами (`driver` / `1234`, `passenger` / `1234`).
- **Расширенная реляционная БД SQLite (`carpooling_v2.db`):**
  - 5 связанных таблиц (`Users`, `Trips`, `Bookings`, `CostExperiments`, `AuditLogs`), внешние ключи `FOREIGN KEY` и индексы производительности (`idx_trips_cities`, `idx_trips_date`, `idx_bookings_trip`).
  - Транзакционное бронирование мест и отмена бронирований с автоматическим возвратом свободных мест в рейс.
  - Журнал системного аудита `AuditLogs`.
- **Обновлённый многовкладочный интерфейс `MainForm` (4 вкладки):**
  - *🔍 Поиск и бронирование* — подбор маршрута по городам и мгновенная бронь на профиль авторизованного пользователя;
  - *➕ Опубликовать поездку* — регистрация нового рейса водителем;
  - *📊 Вычислительный эксперимент* — матрица моделирования себестоимости и распределения расходов на 1..4 попутчиков с расчетом годовой экономии;
  - *📋 Бронирования, аудит и экспорт* — управление заявками, просмотр журнала аудита и экспорт реестров в CSV (`UTF-8 BOM`).
