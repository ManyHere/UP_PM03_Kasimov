## 1. Описание программного комплекса

Программный комплекс **«Сервис поиска попутчиков»** предназначен для автоматизации поиска и организации совместных автомобильных поездок (карпулинга), учета маршрутов водителей и заявок пассажиров на бронирование свободных мест в реляционной базе данных SQLite, а также проведения вычислительного эксперимента по моделированию себестоимости поездки и оптимизации распределения затрат (Cost-Sharing Model).

---

## 2. Архитектура и версии программы

### Версия 1.0 (Релиз v1.0 — Базовая консольная версия)
- Консольный интерактивный интерфейс (`main.py --cli`).
- Локальная база данных SQLite (`carpooling_v1.db`):
  - Таблица `trips`: учет маршрутов, дат, водителей, автомобилей, свободных мест и стоимости проезда.
  - Таблица `bookings`: оформление и фиксация броней пассажиров.
  - Таблица `cost_experiments`: сохранение результатов численных экспериментов.
- Вычислительный эксперимент (`experiment.py`):
  - Расчет прямых топливных затрат: $C_{fuel} = (D \cdot C_{cons} / 100) \cdot P_{fuel}$.
  - Учет амортизации: $C_{deprec} = D \cdot k_{deprec}$.
  - Моделирование распределения затрат на 1..4 попутчиков и расчет финансовой экономии водителя.

### Версия 2.0 (Релиз v2.0 — Графическая версия с GUI, расширенной аналитикой и экспортом)
- Оконный графический интерфейс пользователя на Tkinter / ttk (`gui.py`):
  - Вкладка **«🔍 Поиск и бронирование»**: фильтрация маршрутов по городам отправления и прибытия, просмотр свободных мест, мгновенное оформление бронирования.
  - Вкладка **«➕ Опубликовать поездку»**: удобная экранная форма для добавления маршрутов водителями.
  - Вкладка **«📊 Вычислительный эксперимент»**: интерактивное моделирование себестоимости поездки, расчет расхода топлива, амортизации, доли на одного человека, экономии за рейс и прогноза годовой экономии при регулярных поездках.
  - Вкладка **«📋 Управление бронями и Экспорт»**: просмотр истории заявок, отмена бронирования с автоматическим возвратом мест в рейс, выгрузка данных в CSV.
- Расширенная база данных SQLite (`carpooling_v2.db`):
  - Индексация таблиц (`idx_trips_cities`, `idx_trips_date`, `idx_bookings_trip`) для ускорения запросов.
  - Аудит-логирование событий системы (таблица `audit_logs`).
  - Экспорт реестров поездок и бронирований в формат CSV для последующего анализа в MS Excel.

## 3. Системные требования и запуск

- **ОС:** Windows 10 / 11, Linux, macOS.
- **Python:** 3.10 или выше (со стандартным модулем Tkinter).
- **СУБД:** Встроенная SQLite 3.

### Команды запуска:
- **Запуск графического интерфейса (GUI):**
  ```bash
  python main.py
  ```
- **Запуск в консольном режиме (CLI):**
  ```bash
  python main.py --cli
  ```
