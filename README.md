## Версии проекта

### Версия 2.0 (Релиз v2.0 — Оптимизированная версия)
Результат ревьюирования и модернизации программного модуля:
- 🖥️ **Графический интерфейс пользователя (GUI)** на `tkinter`/`ttk` (`gui.py`):
  - Поля ввода параметров с валидацией;
  - Карточка результатов с цветовой индикацией уровня надежности;
  - Табличный компонент `Treeview` для просмотра истории из базы данных SQLite;
  - Интерактивные функции: добавление, удаление, экспорт в CSV.
- 🗄️ **Расширенная реляционная база данных SQLite (`database.py`)**:
  - Создана таблица `experiments` с расширенными метриками;
  - Добавлена дочерняя таблица `experiment_logs` для аудита событий;
  - Создан индекс `idx_module_name` для оптимизации выборок;
  - Реализован экспорт отчетов в формат CSV.
- 📊 **Углубленный математический анализ (`experiment.py`)**:
  - Расчет выборочной дисперсии и стандартного отклонения;
  - Вычисление 95% доверительного интервала для средней наработки на отказ;
  - Классификация надежности программного модуля.

### Версия 1.0 (Релиз v1.0 — Базовая версия)
- Консольный интерфейс командной строки;
- Базовая схема базы данных SQLite (одна таблица);
- Моделирование надежности методом Монте-Карло с вычислением вероятности безотказной работы и MTTF.
