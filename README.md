## Описание проекта

Программный комплекс **«Сервис поиска попутчиков»** предназначен для организации совместных автомобильных поездок, подбора попутчиков по междугородним маршрутам, учета бронирования пассажирских мест в базе данных SQLite и проведения вычислительного эксперимента по моделированию себестоимости поездки и оптимизации деления транспортных расходов между водителем и попутчиками (Carpooling Cost-Sharing Model).

---

## Версии программного комплекса

### Релиз v1.0 (Консольная версия CLI)
- Консольный интерфейс пользователя (`main.py`).
- Локальная база данных SQLite (`carpooling_v1.db`):
  - Таблица `trips`: учет маршрутов, дат, водителей, автомобилей, свободных мест и тарифов.
  - Таблица `bookings`: оформление и фиксация броней пассажиров.
  - Таблица `cost_experiments`: сохранение результатов численных экспериментов.
- Вычислительный эксперимент (`experiment.py`):
  - Расчет прямых топливных затрат: $C_{fuel} = (D \cdot C_{cons} / 100) \cdot P_{fuel}$.
  - Учет эксплуатационной амортизации: $C_{deprec} = D \cdot k_{deprec}$.
  - Моделирование распределения затрат на 1, 2, 3 и 4 попутчиков и определение чистой финансовой экономии водителя.
