## Версия 1.0 (Релиз v1.0 — Базовая версия)
- Среда разработки: Microsoft Visual Studio 2022 (.NET 9.0, C# Windows Forms).
- База данных SQLite (`carpooling_v1.db` через `Microsoft.Data.Sqlite`): таблицы `Trips` и `CostExperiments`.
- Функционал v1.0:
  - Просмотр и фильтрация списка поездок по городам отправления и назначения (`DataGridView`);
  - Публикация новых поездок в БД SQLite;
  - Вычислительный эксперимент (`ExperimentCalculator.cs`): расчёт топливных затрат, амортизации, себестоимости на 1 человека и экономии водителя.
