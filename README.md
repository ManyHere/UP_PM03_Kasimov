## Версия 1.0 (Релиз v1.0)
Базовая версия программы для проведения вычислительного эксперимента методом статистических испытаний (Монте-Карло) с сохранением результатов в реляционную базу данных SQLite.

### Состав модулей:
- `main.py` — консольный интерфейс управления программой и отображения результатов;
- `experiment.py` — математический модуль статистического моделирования надежности программных модулей по экспоненциальному распределению;
- `database.py` — модуль взаимодействия со встраиваемой СУБД SQLite (создание схемы данных, сохранение серий расчетов, выборка истории);
- `.gitignore` — конфигурация исключений Git для отслеживания исходного кода.

### Запуск:
```bash
python main.py
```
